# Minesweeper UI concepts

Open each HTML file directly in a browser. Use the **Playing**, **Menu**, and
**Victory** tabs at the top right of each concept to preview the main states.

1. `classic-refined.html` — restrained, warm, and closest to traditional Minesweeper.
2. `midnight-neon.html` — dark arcade presentation with cyan/violet accents.
3. `garden-playful.html` — friendly, tactile, and colorful.

These are selection prototypes only. They do not change the SFML game.
